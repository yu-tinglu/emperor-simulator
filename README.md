# 皇帝模擬器

單檔 HTML 的歷史模擬遊戲。你是一位皇帝：批奏摺、處理災異與外交、安排科舉、節制邊將，並在身後被史官寫進本紀。繁體中文，可直接在手機瀏覽器遊玩。

## 遊玩
直接開啟 `index.html` 即可，不需要伺服器或安裝。若想公開試玩，可在 GitHub 的 Settings → Pages 選擇 `main` 分支根目錄。

## 結構
原始碼分成多個檔案，由 `build.py` 合併成單一的 `index.html`。

| 檔案 | 內容 |
| --- | --- |
| `core.js` | 常數、新局建立、編年史、日期 |
| `sim.js` | 經濟、人物、陰謀、外邦、月度與年度結算 |
| `act.js` | 玩家行動、廷議、人物故事線 |
| `story.js` | 序章、歷史回響、天命志向、兩難抉擇、典藏與成就 |
| `world.js` | 災異、使節、科舉、邊將、地方經濟、事件庫、難度、存檔相容 |
| `art.js` | 開始畫面與劇本的 SVG 剪影 |
| `ui.js` | 介面、輿圖、關係圖、時間軸、設定 |
| `style.css` | 樣式 |

## 建置
```
python3 build.py
```
會讀取上述檔案並寫出 `index.html`。字體（LXGW WenKai TC、馬善政）由 Google Fonts 載入。

## 開發用測試
`dev/` 內是測試腳本，原本在作者的開發環境中撰寫，路徑可能需要依你的環境調整。
- `test_bot.js`：在 Node 中以簡單策略跑整局，檢查有無錯誤（可用環境變數 `SC`、`NS`、`DIFFV` 指定劇本、局數、難度）。
- `migtest.js`：檢查舊存檔補欄位後仍能繼續運行。
- `browser_fuzz2.py`、`flow.py`：以 Playwright 在瀏覽器中隨機點擊與走流程。

存檔與典藏都保存在瀏覽器的 localStorage，不會上傳。
